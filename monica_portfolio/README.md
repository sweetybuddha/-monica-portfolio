# Monica Buddha — Portfolio Website

A responsive single-page portfolio built with HTML and CSS, based on the supplied resume.

## Run locally
1. Extract the ZIP (if using the ZIP).
2. Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a GitHub repository named `monica-portfolio` (or another name).
2. Upload `index.html` to the repository root.
3. Open repository **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish and use the URL shown in Settings → Pages.

Review your contact details and resume facts before publishing publicly.
